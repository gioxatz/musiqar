# musiqar

A mobile application developed for the "Human-Computer Interaction" course at NTUA. Musiqar allows users to create, publish, and enroll in music courses. Users can complete courses, track their progress, and view their global leaderboard rankings. Additionally, the platform features an AR-like capability, letting users visualize musical instruments in their environment. Developed using the Flutter framework.
